El error Failed to allocate directory watch: Too many open files ocurre porque tu sistema WSL ha alcanzado el límite máximo de archivos o directorios que puede monitorear de forma simultánea (el límite de inotify).Esto es extremadamente común en WSL cuando se instalan actualizaciones, herramientas pesadas como Docker, o cuando utilizas entornos de programación (como Node.js, Python o VS Code) que vigilan muchos archivos a la vez.Para solucionarlo de forma permanente, debes aumentar los límites de inotify en tu Linux siguiendo estos pasos:1. Aumentar el límite de forma inmediataEjecuta el siguiente comando en tu terminal de WSL para subir los límites de monitoreo temporalmente sin reiniciar:bashsudo sysctl fs.inotify.max_user_watches=524288
sudo sysctl fs.inotify.max_user_instances=512
